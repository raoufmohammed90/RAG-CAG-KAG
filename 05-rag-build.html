    Inside now

    Four components, connected like a network.The ingestion app sits in the middle and talks to each of the others. They never talk to each other.
    The knowledge sits in file storage.The same three documents CAG loaded whole on page 03.
    The app fetches a file and cuts it into chunks.Here, along its sections: one topic per chunk. The leave policy becomes 16 chunks.
    The embedding model turns each chunk into a vector.Text goes out, a long list of numbers comes back. Similar meaning, similar numbers.
    The app writes vector, text and label as one row.The vector is for finding the chunk. The text is what the LLM will read. The label says where it came from.
    3 documents, 48 chunks, 48 vectors.Every file takes the same route. Chunks travel in batches.
    Chunks about the same thing sit close together.Drawn in 2 dimensions; real vectors have hundreds. Search will use these distances.
    The index is ready. Now, the questions.Built once, ahead of time. When a file changes, only that file takes the route again.
