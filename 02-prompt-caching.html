    Stable first, changing last

    The cache matches from the very first token. Put what never changes at the start, and put anything that changes after the marker.

    The date changes daily, so nothing after it ever matches
    Order that caches well: Tool definitions→ System prompt→ Documents→ Earlier turns→ New question, dates, IDs

    Move the marker as the chat grows

    Put a marker at the end of the newest turn. The next request then reuses everything up to that point, so only the latest turn goes through the network.
